# 审核员 · Auditor

一个 30 秒就能玩完的竖屏反应小游戏：你是内容审核员，规则每 5 张卡换一次，判错 3 次就被开除。

**在线玩**：https://wenyumoney.github.io/auditor-game/

## 规则

- 屏幕上有一条当前规则（例如「不到 6 个字 → 驳回」「含『免费』→ 驳回」）
- 每张卡有倒计时，时间从 4.2 秒逐张缩短，最快 2.6 秒
- 判对加分（带连对加成），判错扣一颗心；三颗心没了就开除
- 每答满 5 张，规则**随机换一条**，绝不和上一条重复

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 游戏本体，canvas 1080×1920，单文件无依赖 |
| `data.js` | 12 条规则 + 110 张卡片的数据层 |

零依赖、零联网、无外部素材。双击 `index.html` 也能玩。
